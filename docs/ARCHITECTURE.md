# 系统架构文档

## 系统概述

BCM车窗控制器采用分层架构设计，实现了硬件抽象、业务逻辑和用户界面的分离。

## 架构层次

```
┌─────────────────────────────────────┐
│         GUI Layer (Python)          │
│   - Tkinter界面                     │
│   - 可视化控制                      │
│   - HIL测试                         │
└─────────────────────────────────────┘
                 ↕
┌─────────────────────────────────────┐
│    Application Layer (main.c)       │
│   - 状态管理                        │
│   - 用户输入处理                    │
│   - 系统初始化                      │
└─────────────────────────────────────┘
                 ↕
┌─────────────────────────────────────┐
│  Business Logic (window_controller) │
│   - 车窗控制逻辑                    │
│   - 防夹算法                        │
│   - 状态机                          │
└─────────────────────────────────────┘
                 ↕
┌─────────────────────────────────────┐
│    HAL Layer (stm32_hal_impl.c)     │
│   - 电机驱动                        │
│   - ADC采样                         │
│   - PWM控制                         │
└─────────────────────────────────────┘
                 ↕
┌─────────────────────────────────────┐
│          Hardware                    │
│   - STM32 MCU                       │
│   - H桥驱动                         │
│   - 电流传感器                      │
└─────────────────────────────────────┘
```

## 核心组件

### 1. Window Controller (业务逻辑层)

#### 功能职责
- 车窗位置管理
- 运动控制
- 防夹检测
- 状态机管理

#### 关键数据结构
```c
typedef struct {
    uint8_t position;           // 当前位置 (0-100)
    uint8_t target_position;    // 目标位置
    WindowState_t state;        // 当前状态
    ControlMode_t ctrl_mode;    // 控制模式
    uint16_t current_mA;        // 电机电流
    bool anti_pinch_enabled;    // 防夹使能
    uint32_t last_update_ms;    // 更新时间戳
    uint8_t error_code;         // 错误代码
} WindowController_t;
```

#### 状态机设计
```
IDLE → MOVING_UP → IDLE
  ↓       ↓
  ↓    ANTI_PINCH_ACTIVE
  ↓       ↓
  → MOVING_DOWN → IDLE
```

### 2. HAL Layer (硬件抽象层)

#### 接口定义
```c
void Window_HAL_InitMotor(void);
void Window_HAL_SetMotorSpeed(int8_t speed);
uint16_t Window_HAL_ReadCurrent(void);
void Window_HAL_SetPWM(uint8_t duty_cycle);
```

#### 设计优势
- 平台无关性
- 易于移植
- 便于测试
- 支持模拟

### 3. GUI Layer (测试界面)

#### 组件结构
- 窗口控制面板 × 4
- 全局控制面板
- 状态监视器
- 障碍物模拟器

#### 通信机制
- 模拟器模式：直接Python实现
- 实际硬件：可通过串口/CAN通信

## 控制流程

### 上升控制流程
```
用户按下UP按钮
    ↓
设置target_position
    ↓
state = MOVING_UP
    ↓
Update循环:
  - 读取电流
  - 检查防夹
  - 更新位置
  - 控制电机
    ↓
到达目标位置
    ↓
state = IDLE
```

### 防夹检测流程
```
电机运转
    ↓
实时监测电流
    ↓
电流 > 阈值？
    ↓ YES
state = ANTI_PINCH_ACTIVE
    ↓
反向运动10%
    ↓
state = IDLE
```

## 移植指南

### 移植到其他STM32系列

1. 修改`stm32_hal_impl.c`
2. 调整时钟配置
3. 更新引脚定义
4. 重新编译

### 移植到其他MCU

1. 实现HAL接口
2. 保持接口一致性
3. 测试验证
4. 性能调优

## 总结

本架构具有以下优点：
- **模块化**：清晰的层次划分
- **可移植**：硬件抽象良好
- **可测试**：支持HIL测试
- **可扩展**：易于添加新功能
- **安全性**：多重保护机制
